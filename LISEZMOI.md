# Kalil Nutrition — ouvrir le projet

## Lancer l application

```bash
npm run install:all
npm run dev:backend
npm run dev:frontend
```

- Site : http://localhost:5173
- Admin promos : http://localhost:5173/admin
- API : http://localhost:4000/api/health
